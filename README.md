# COVID-19 in India Analysis using Tableau

## Project Overview
This project analyzes COVID-19 data in India using Tableau. The dashboard provides insights into confirmed cases, deaths, recoveries, testing, hospital beds, and vaccination data across different Indian states.

## Tools Used
- Tableau Public
- Microsoft Excel / CSV
- Data Visualization

## Dataset
The project uses COVID-19 datasets containing:
- State-wise COVID-19 data
- Vaccination details
- Testing details
- Hospital bed information
- Age group details
- Individual COVID-19 records

## Project Files
- `final_mini_project.twbx` - Tableau Dashboard
- `covid_19_india` - COVID-19 dataset
- `covid_vaccine_statewise` - Vaccination dataset
- `StatewiseTestingDetails` - Testing data
- `HospitalBedsIndia` - Hospital bed data
- `AgeGroupDetails` - Age group data
- `IndividualDetails` - Individual case data
- `ICMRTestingLabs` - Testing laboratory data
